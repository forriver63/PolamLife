# Art and source inventory

| Path | Contents and origin |
| --- | --- |
| assets/map.webp | The unlettered 1448 × 1086 Po Lam district WebP embedded in the reference index. Used with team permission for this game and its private reviewer handoff. |
| assets/agentopia-logo.png | Original 616 × 262 transparent Agentopia masthead PNG embedded in the same reference. The team authorized reuse in this game and private repository. |
| assets/regions/*.webp | Five original ImageGen scenes created for this prototype. Landmark details follow the overview. The artwork was processed at a 576 × 336 pixel grid and exported at double size. Clickable tenant façades are layered on their own ground positions. |
| assets/mall.webp | Original pixel-art atrium panorama, with a glazed roof, estate skyline, two galleries and six physical bays. |
| assets/world/front-*.webp | Original tenant-specific façades and the shuttered unit. The scene replaces the entire façade on refit. |
| assets/interiors/*.webp | Counter illustrations for 22 businesses and the construction phase. The fifteen new shops have individually illustrated ImageGen interiors. Their three-quarter storefront sprites have transparent backgrounds for placement on each location’s ground plane. |
| assets/world/*.png | Original game sprites for the resident, three neighbors, landmarks and trades. Colors, objects and silhouettes distinguish them at HUD size. |
| assets/items/*.webp | Seven original illustrated ballot products and a maintenance toolbox cropped from an ImageGen sheet made for this game, plus fifteen region-specific product illustrations. |
| assets/crest.svg and src/icons.js | Original district crest and functional vector UI symbols. |
| src/rounds.js and src/regional-products.js | Original product and station illustrations drawn for both timed activities. |
| Project PDF | Team-provided product concept and original sketches. See [the original team PDF](PolamLife_全新游戏概念_组内同步版.pdf). |

The two authorized reference images are extracted from [Agentopia’s index at 750997e](https://github.com/CCiWang/Agentopia_HKdemo/blob/750997e57f27410ff0116674f27e4a46aa8aaa95/index.html). Reference-site screenshots stay in local research. The project records permission for this private handoff, without a blanket license for other uses. The original study and repository inspection are recorded in [reference-study.md](reference-study.md). Shop names, alliance flags, simulation rules and local activity records were created for this pitch. Interface fonts resolve from the presenting machine.
